### MLOPS Experiment Using MLflow

A beginner-friendly MLOps project demonstrating **Experiment Tracking** and **Data Versioning** using MLflow. This project showcases how to log parameters, metrics, and model artifacts, manage dataset versions, and build reproducible machine learning workflows.

**Key Learnings:**

* MLflow Experiment Tracking
* Data Versioning
* Model Management
* Reproducible ML Pipelines
* MLOps Fundamentals

**Tech Stack:** Python, MLflow, Pandas, Scikit-learn

> A simple demo project to understand and practice core MLOps concepts.
